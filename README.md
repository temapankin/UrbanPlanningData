# Overview
This repository focuses on gathering and analyzing data pertinent to urban planning. It includes Jupyter notebooks that handle tasks such as data cleaning, analysis, and visualization related to public transportation and real estate.

## Contents
**Belgrade_BusDataCleaning.ipynb**: A Jupyter notebook dedicated to cleaning and processing bus transportation data for Belgrade.​

**NYC_GTFS_Analysis.ipynb**: This notebook analyzes General Transit Feed Specification (GTFS) data for New York City, offering insights into the city's public transit system.​

**property24_scrapper.ipynb**: A notebook designed to scrape real estate data from Property24, facilitating the collection of property listings for analysis.
