# Overview
This repository contains a collection of Jupyter Notebooks focused on various urban planning data analyses. The projects utilize diverse datasets and analytical methods to explore topics such as public transportation, real estate, and environmental studies.

## Table of Contents 

### Belgrade Bus Data Cleaning
**Notebook**: [`Belgrade_BusDataCleaning.ipynb`](notebooks/Belgrade_BusDataCleaning.ipynb)

A Jupyter notebook dedicated to cleaning and processing bus transportation data for Belgrade, that was later used for [Transmetrika's](https://transmetrika.com/) Belgrade Layer. 

### NYC GTFS Analysis
**Notebook**: [`NYC_GTFS_Analysis.ipynb`](notebooks/NYC_GTFS_Analysis.ipynb)

This notebook analyzes General Transit Feed Specification (GTFS) data for New York City, offering insights into the city's public transit system.​

### Property 24 Scrapper
**Notebook**: [`property24_scraper.ipynb`](notebooks/property24_scraper.ipynb)

A notebook designed to scrape real estate data from Property24, facilitating the collection of property listings for analysis.


### Urban Tree Canopy Analysis on CUNY Campuses
**Notebook**: [`urban_tree_canopy_cuny.ipynb`](notebooks/urban_tree_canopy_cuny.ipynb)

This notebook presents a spatial analysis and data vizualization of urban tree canopy coverage across City University of New York (CUNY) campuses for [NYC Climate Justice Hib](https://centerforthehumanities.org/project/climate-justice-hub/).
